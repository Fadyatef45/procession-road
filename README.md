# طريق الموكب — رحلة العريس

شريحة أفقية طويلة من بيت الأب لبيت العروس، وعليها ١٤ محطة. أيقونة العريس 🤵 تتحرك مع كل ضغطة وتفتح الطقس ثم الآية.

## التشغيل في VS Code
1. افتح فولدر `procession-road` (File ← Open Folder).
2. كليك يمين على `index.html` ← **Open with Live Server** (إضافة Live Server)، أو افتحه مباشرة في المتصفح.

## هيكل المشروع
```
procession-road/
├── index.html
├── css/style.css
├── js/                  (الترتيب مهم وهو نفس ترتيب index.html)
│   ├── data.js          المراحل والآيات وصورها
│   ├── road.js          رسم الطريق والمحطات والبيوت
│   ├── journey.js       حركة العريس ولوحة الطقس والآية (show / adv / go)
│   ├── controls.js      الضغط والأزرار والكيبورد وملء الشاشة
│   └── app.js           البداية (build عند التحميل والتغيير في حجم الشاشة)
└── assets/img/          صور المراحل stage-01.jpg … stage-14.jpg
```

## طريقة التحكم
- ضغطة على الشاشة أو مسافة أو Enter أو ← : العريس يتحرك للمحطة التالية ويظهر الطقس، والضغطة اللي بعدها تظهر الآية، ثم تتحرك للمحطة التالية.
- → أو زر «→»: رجوع محطة.
- الضغط على محطة: القفز لها.

## تعديلات شائعة
- **نصوص المراحل والآيات:** المصفوفة `D` في `data.js`: `[الاسم، English، الطقس، مرجع الآية، نص الآية]`.
- **صور المراحل ٦ و٧ (عليهم أيقونة):** حط `stage-06.jpg` و`stage-07.jpg` في `assets/img/` وغيّر العنصرين السادس والسابع في المصفوفة `IMG` داخل `data.js`.
- **المسافة بين المحطات:** `SP` و`PAD` في أول `js/road.js`.
- **سرعة حركة العريس:** `transition` على `#gr` في `css/style.css`.
- **الألوان:** المتغيرات في أول `style.css` (فيها وضع داكن تلقائي).
